# ⚡ Hall of Magical Innovations

A **Harry Potter–themed collaboration platform** where developers showcase their projects inside magical houses and send collaboration requests using **Owl Post**.

This project combines a **fantasy Hogwarts UI** with a **project-sharing platform**, allowing users to add projects, browse houses, and collaborate with others.

---

## ✨ Features

### 🔐 Authentication System

* Login and Signup interface
* Tab-based switching between login and signup
* User session handling
* Logout functionality

---

### 🏰 Hogwarts Houses

Users can explore projects grouped into the four famous houses:

* 🦁 **Gryffindor**
* 🐍 **Slytherin**
* 🦅 **Ravenclaw**
* 🦡 **Hufflepuff**

Each house represents a **technology domain or innovation area**.

Users can:

* Browse projects inside houses
* View project details
* Add new projects

---

### 📚 Project Showcase

Each project includes:

* **Project Title**
* **Description**
* **Tech Stack**
* **House Category**
* **Project Snapshot Image**
* **Student/Owner Name**

Users can:

* ➕ Add projects
* ✏️ Edit projects
* 🗑️ Delete projects

---

### 🦉 Owl Post Collaboration System

Inspired by Hogwarts owl messaging.

Users can:

* Send collaboration requests to project owners
* Add an optional message
* View incoming requests
* Track sent owls

Sections include:

* 📬 **Incoming Requests**
* 📤 **Sent Owls**

---

## 🧪 How to Run the Project

1. Clone the repository

```bash
git clone https://github.com/Yaswanth8407/hall-of-magical-innovations.git
```

2. Open the project folder

```bash
cd hall-of-magical-innovations
```

3. Open `index.html` in your browser.

Or use **Live Server (VS Code)** for better development experience.

## 🎮 How to Use

### 1️⃣ Login / Signup

Create an account or login to enter the magical hall.

### 2️⃣ Choose a House

Select a Hogwarts house to explore projects.

### 3️⃣ Add Your Project

Click **Add Project** and fill in:

* Title
* Description
* Tech Stack
* House
* Image

### 4️⃣ Send an Owl

If you like someone's project, send them a **collaboration owl**.

### 5️⃣ Manage Requests

Check the **Owl Post panel** to:

* Accept collaboration requests
* Track sent requests
